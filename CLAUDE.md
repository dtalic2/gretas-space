# Greta's Space

Games for Greta. They're published with GitHub Pages from the
`claude/snake-game-versions-aemWv` branch, so each game is playable at
`https://dtalic2.github.io/gretas-space/<folder>/`.

## Stay on GitHub

- Give links that are on GitHub: the GitHub Pages site above, or github.com
  itself. Don't send links through third-party services such as
  raw.githack.com, jsDelivr or htmlpreview, even to show an older version.
- If an older version needs a playable link, publish a copy on GitHub Pages
  (for example `milbil-cafe-v1/`) rather than using an outside host.
- Avoid third-party websites wherever possible, in what you send and in the
  games themselves: bundle fonts, images and scripts in the repo instead of
  loading them from a CDN.
- When something really does need a third-party website, warn first and say
  which site and why, before using it or sending a link to it.
